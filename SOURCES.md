# Sources checked while preparing this M0 package

- Folktables repository documentation: ACSIncome target `PINCP > 50000`, the adult/work/income eligibility filter, and the standard ten feature columns. https://github.com/socialfoundations/folktables
- U.S. Census Bureau: ACS PUMS data access and person/housing file documentation. https://www.census.gov/programs-surveys/acs/microdata/access.html
- U.S. Census Bureau 2017 PUMS ReadMe: `ADJINC / 1,000,000` is the income inflation adjustment factor to 2017 dollars. https://www2.census.gov/programs-surveys/acs/tech_docs/pums/ACS2017_PUMS_README.pdf
- ManimGX PyPI release page: Python >=3.13, release 0.1.1, wheel/license details. https://pypi.org/project/manimgx/
- ManimGX Quickstart and rendering docs: 2D `Scene`, `Square`, `Text`, `VGroup`, `inspect`, `render`, resolution and FPS options. https://manimgx.academa.ai/user-guide/quickstart/ and https://manimgx.academa.ai/user-guide/rendering/

These sources support task-definition and tooling facts only. They do not establish that SliceAudit is novel, that a particular empirical regression exists, or that the proposed cluster inference is calibrated. The latter must be demonstrated by simulation before G0.
